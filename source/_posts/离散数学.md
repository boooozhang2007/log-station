# 离散数学及其应用 (Discrete Mathematics)

## 第一章：逻辑与证明 (Logic & Proofs)
- **1. 命题逻辑 (Propositional Logic)**
    - 基础概念
        - 命题：真值唯一的陈述句
        - 逻辑联结词：¬ (非), ∧ (且), ∨ (或), ⊕ (异或), → (蕴含), ↔ (双条件)
    - [核心公式] 逻辑等价式
        - 德摩根定律 (De Morgan)：¬(p ∧ q) ≡ ¬p ∨ ¬q
        - 蕴含消除：p → q ≡ ¬p ∨ q
        - 逆否命题：p → q ≡ ¬q → ¬p (同真同假)
    - [题型] 范式求解
        - 主析取范式 (DNF/Sum of Products)
            - [技巧] 找真值表结果为T的行，变量间用∧，行间用∨
        - 主合取范式 (CNF/Product of Sums)
            - [技巧] 找真值表结果为F的行，变量取反后用∨，行间用∧
- **2. 谓词逻辑 (Predicate Logic)**
    - 量词
        - 全称量词 ∀ (For all)
        - 存在量词 ∃ (There exists)
    - [技巧] 量词否定变换
        - ¬∀x P(x) ≡ ∃x ¬P(x) (否定穿过量词，量词变号)
    - [难点] 嵌套量词顺序
        - ∀x∃y (对任意x，都有对应的y) ≠ ∃y∀x (存在一个y，应对所有x)
- **3. 证明方法**
    - 直接证明 (Direct Proof)
        - 设 p 为真，推导 q 为真
    - [高频题型] 反证法 (Proof by Contradiction)
        - [技巧] 假设结论不成立(¬q) → 推导出矛盾(r ∧ ¬r) → 故原命题成立
        - 适用：证明无理数、素数无限多
    - 分类讨论 (Proof by Cases)
        - 必须覆盖所有可能的情况

## 第二章：集合、函数与算法 (Sets, Functions)
- **1. 集合论 (Sets)**
    - 集合运算
        - 并(∪), 交(∩), 差(-), 补(A̅), 对称差(⊕)
    - 幂集 P(A)
        - [公式] 元素个数 = 2^|A|
    - [题型] 证明集合相等 A = B
        - [万能解法] 双向包含法：
            1. 证 A ⊆ B (任取 x∈A ⇒ x∈B)
            2. 证 B ⊆ A (任取 x∈B ⇒ x∈A)
- **2. 函数 (Functions)**
    - 性质判定
        - 单射 (One-to-One)：f(x)=f(y) ⇒ x=y (自变量不同，函数值必不同)
        - 满射 (Onto)：值域 = 上域 (所有y都被覆盖)
        - 双射 (Bijection)：单射 + 满射 ⇒ 存在逆函数
    - 特殊函数
        - 地板函数 floor(x) / 天花板函数 ceil(x)
- **3. 算法复杂度**
    - [题型] 大O表示法 (Big-O)
        - 定义：存在 C, k，当 x>k 时，|f(x)| ≤ C|g(x)|
        - [技巧] 抓大头：只保留最高次幂，忽略系数
        - 常见排序：O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(2^n) < O(n!)

## 第三章：数论 (Number Theory)
- **1. 整除与同余**
    - 模运算性质
        - a ≡ b (mod m) ⇔ m | (a-b)
        - (a + b) mod m = ((a mod m) + (b mod m)) mod m
    - 素数与GCD
        - 算术基本定理：唯一分解定理
        - 欧几里得算法 (辗转相除法)：求 gcd(a, b)
- **2. [难点] 求解线性同余方程**
    - 形式：ax ≡ b (mod m)
    - [解题四步走]
        1. 计算 d = gcd(a, m)
        2. 判别：若 d 不能整除 b，则无解
        3. 扩展欧几里得：求 s, t 使得 as + mt = d
        4. 通解：x = s * (b/d) + k * (m/d)
- **3. 核心定理应用**
    - 费马小定理
        - 若 p 为素数，a^(p-1) ≡ 1 (mod p)
        - [技巧] 用于简化大数幂运算 (降次)
    - 中国剩余定理 (CRT)
        - [技巧] 解决模数互质的同余方程组，使用构造法求解

## 第四章：归纳与递归 (Induction & Recursion)
- **1. 数学归纳法 (Proof by Induction)**
    - [必考大题] 归纳法三部曲
        1. 基础步骤 (Basis)：验证 n=1 (或初始值) 时命题成立
        2. 归纳假设 (Hypothesis)：假设 n=k 时命题成立
        3. 归纳步骤 (Step)：利用假设，证明 n=k+1 时命题也成立
    - 强归纳法
        - 假设 P(1)...P(k) 全部成立，证明 P(k+1)
- **2. 递归关系求解**
    - [题型] 二阶线性齐次递归 (Linear Homogeneous Recurrence)
        - 形式：a_n = c1*a_{n-1} + c2*a_{n-2}
        - [解题步骤]
            1. 写特征方程：r^2 - c1*r - c2 = 0
            2. 求根 r1, r2
            3. 情况A (两根不同)：a_n = α(r1)^n + β(r2)^n
            4. 情况B (两根相同)：a_n = α(r1)^n + β*n*(r1)^n
            5. 代入初值求 α, β

## 第五章：计数 (Counting)
- **1. 基础计数原理**
    - 加法原理 (分情况) vs 乘法原理 (分步骤)
    - 容斥原理 (Inclusion-Exclusion)
        - |A∪B| = |A| + |B| - |A∩B|
        - 应用：求错排数、求不能被某些数整除的数的个数
- **2. 鸽巢原理 (Pigeonhole Principle)**
    - 基础版：N+1个物体放入N个盒子，至少一个盒子有2个
    - [技巧] 广义版 (Generalized)
        - N个物体，k个盒子，至少一个盒子有 ⌈N/k⌉ 个物体
        - 关键在于识别什么是“鸽子”，什么是“笼子”
- **3. 排列组合**
    - 排列 P(n,r)：有序
    - 组合 C(n,r)：无序
    - [难点] 允许重复的组合 (Stars and Bars)
        - 题目特征：n个相同物品分给r个不同的人
        - [公式] C(n+r-1, n) 或 C(n+r-1, r-1) (隔板法)

## 第六章：关系 (Relations)
- **1. 关系的性质 (Properties)**
    - 自反性 (Reflexive)：对角线全1
    - 对称性 (Symmetric)：矩阵关于对角线对称
    - 反对称性 (Antisymmetric)：aRb 且 bRa ⇒ a=b (矩阵对称位置不能同时为1)
    - 传递性 (Transitive)：若aRb且bRc ⇒ aRc
- **2. 关系的闭包 (Closures)**
    - 自反闭包、对称闭包
    - [算法] 传递闭包：Warshall 算法 (通过矩阵逻辑加运算)
- **3. 等价关系与偏序关系**
    - 等价关系 (Equivalence)
        - 满足：自反 + 对称 + 传递
        - 结果：产生等价类 (Partition)，如模m同余
    - 偏序关系 (Partial Order)
        - 满足：自反 + 反对称 + 传递
        - [工具] 哈斯图 (Hasse Diagrams)：去自环、去传递边、向上画
        - [概念辨析] 极大/极小元 (Maximal/Minimal) vs 最大/最小元 (Greatest/Least)

## 第七章：图论 (Graphs)
- **1. 图的基本术语**
    - 握手定理：度数之和 = 2 * 边数 (奇度数顶点必偶数个)
    - 二分图 (Bipartite)：点集可分为两组，组内无边
    - 邻接矩阵 vs 关联矩阵
- **2. 连通性与回路**
    - 欧拉回路 (Euler Circuit)
        - 定义：经过每条边一次且回到起点
        - [判定] 连通图 + 所有顶点度数均为偶数
    - 哈密顿回路 (Hamilton Circuit)
        - 定义：经过每个顶点一次且回到起点
        - [判定] NPC问题，常用Dirac定理作为充分条件
- **3. 最短路径与平面图**
    - [算法] Dijkstra 算法
        - 贪心策略，维护起点到各点的距离数组，每次选最近的未访问点
    - 平面图欧拉公式
        - r = e - v + 2 (面数 = 边 - 点 + 2)
    - 图着色
        - 色数 χ(G)，平面图四色定理 (χ(G)≤4)

## 第八章：树 (Trees)
- **1. 树的性质**
    - 连通且无环
    - 边数 e = v - 1
    - m叉树的叶子节点计算公式
- **2. 树的遍历 (Traversals)**
    - 前序 (Preorder)：根→左→右 (波兰表达式)
    - 中序 (Inorder)：左→根→右
    - 后序 (Postorder)：左→右→根 (逆波兰表达式)
- **3. [算法] 最小生成树 (MST)**
    - 目标：连接所有点且边权之和最小
    - Prim 算法
        - [技巧] “加点法”：从任意点开始，每次抓一条连通已知集合与未知集合的最短边
    - Kruskal 算法
        - [技巧] “加边法”：边权排序，从小到大选边，只要不构成回路就加入
